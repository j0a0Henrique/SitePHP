# 🍔 Taquara Delivery

Projeto em PHP que consome uma API fake para exibir **comidas** e **restaurantes** em uma interface moderna com HTML e CSS. O projeto simula um pequeno sistema de delivery.

## 📦 Funcionalidades

- ✅ Lista de comidas com nome, preço, avaliação, tempo de entrega e imagem
- ✅ Lista de restaurantes com nome, avaliação, descrição e logo
- ✅ Estilo dark mode para o site
- ✅ Cartões de restaurante com fundo branco
- ✅ Botões "Ver mais" para detalhes individuais
- ✅ Layout responsivo simples com Flexbox

---

## 🛠 Tecnologias utilizadas

- PHP
- HTML5
- CSS3 (puro, sem frameworks)
- API pública `https://apifakedelivery.vercel.app/`
